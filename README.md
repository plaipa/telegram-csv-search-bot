# ربات جستجو در فایل‌های CSV و DB

هر فایل **CSV** و دیتابیس **SQLite** (`.db`، `.sqlite`) که در پوشه‌ی `data/` بگذارید، خودکار ثبت می‌شود و از داخل تلگرام می‌توانید در آن جستجو کنید.

## امکانات
- بررسی خودکار پوشه هر ۶۰ ثانیه: فایل جدید ثبت می‌شود، فایل تغییرکرده دوباره ثبت می‌شود، فایل حذف‌شده از نتایج حذف می‌شود
- زیرپوشه‌ها هم خوانده می‌شوند
- در فایل‌های `.db` همه‌ی جدول‌ها قابل جستجو هستند
- فایل‌های چند گیگابایتی (خواندن خط‌به‌خط، مصرف رم ثابت)
- فایل‌هایی که در حال کپی‌اند صبر می‌کنند تا کپی تمام شود
- یکسان‌سازی حروف و اعداد فارسی/عربی (ي/ی، ك/ک، ۱۲۳/123)
- تشخیص خودکار encoding (UTF-8، Windows-1256) و جداکننده‌ی CSV
- جستجوی چندکلمه‌ای، پیشوندی، دقیق با "گیومه"، صفحه‌بندی
- پشتیبانی از پروکسی VPN برای جاهایی که تلگرام فیلتر است
- فقط **توکن ربات** لازم است (API_ID و API_HASH لازم نیست)

## راه‌اندازی
> - روی کامپیوتر خودتان (مک/ویندوز/لینوکس): [docs/local.md](docs/local.md)
> - روی سرور **Oracle Cloud Free Tier**: [docs/oracle-cloud.md](docs/oracle-cloud.md)

خلاصه:
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # BOT_TOKEN و ADMIN_IDS را پر کنید
python -m csvbot.check      # بررسی تنظیمات و پیدا کردن خودکار پروکسی VPN
python -m csvbot.bot
```
بعد فایل‌ها را در پوشه‌ی `data/` کپی کنید.

## استفاده
| کار | روش |
|---|---|
| جستجو | فقط متن را بفرستید |
| جستجوی دقیق | `"علی رضایی"` |
| لیست فایل‌ها | `/files` |
| بررسی فوری پوشه (ادمین) | `/reload` |
| افزودن فایل کوچک (ادمین) | فایل زیر ۲۰ مگابایت را به ربات بفرستید |

## کارایی
- CSV با ۶ میلیون ردیف (۴۷۰ مگابایت): ثبت حدود ۲.۵ دقیقه
- دیتابیس SQLite با ۲ میلیون ردیف: ثبت حدود ۳۰ ثانیه
- جستجو: معمولاً زیر ۲۰۰ میلی‌ثانیه
- حجم `index.db`: حدود ۲ برابر حجم داده‌ها
