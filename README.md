# ربات جستجو در فایل‌های CSV تلگرام

این ربات فایل‌های CSV کانال تلگرام را می‌خواند، محتوای آن‌ها را در یک پایگاه داده SQLite (با جستجوی تمام‌متن FTS5) ذخیره می‌کند و امکان جستجو را از داخل تلگرام می‌دهد.

## امکانات
- فایل‌های CSV جدیدی که در کانال گذاشته می‌شوند **خودکار** ثبت می‌شوند
- فایل‌های قدیمی کانال را به ربات **فوروارد** کنید تا ثبت شوند (فقط ادمین)
- یکسان‌سازی حروف فارسی و عربی (ي/ی، ك/ک) و اعداد (۱۲۳ / 123)
- تشخیص خودکار encoding (UTF-8 و Windows-1256 اکسل قدیمی) و جداکننده (`,` `;` تب `|`)
- جستجوی چندکلمه‌ای، جستجوی پیشوندی، جستجوی دقیق با "گیومه"، صفحه‌بندی نتایج
- محدود کردن دسترسی به کاربران مشخص

## راه‌اندازی
1. در [@BotFather](https://t.me/BotFather) ربات بسازید و توکن را بگیرید.
2. ربات را در کانال **ادمین** کنید (تا پست‌های کانال را دریافت کند).
3. شناسه عددی خود را از [@userinfobot](https://t.me/userinfobot) بگیرید.
4. نصب و اجرا:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # مقادیر را پر کنید
   python -m csvbot.bot
   ```
5. فایل‌های CSV قدیمی کانال را به ربات فوروارد کنید (ربات API تلگرام به تاریخچه کانال دسترسی ندارد).

## استفاده
| کار | روش |
|---|---|
| جستجو | فقط متن را بفرستید، یا `/search متن` |
| جستجوی دقیق | `"علی رضایی"` |
| لیست فایل‌ها | `/files` |
| حذف فایل (ادمین) | `/delete شناسه` |

## فایل‌های بزرگ‌تر از ۲۰ مگابایت
Bot API تلگرام اجازه دانلود فایل‌های بالای ۲۰MB را نمی‌دهد. این فایل‌ها را دانلود کنید و مستقیم وارد کنید:
```bash
python import_csv.py file1.csv file2.csv
```
