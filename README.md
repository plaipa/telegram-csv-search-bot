# ربات تلگرام جستجو در فایل‌های CSV و DB

این ربات تلگرام همه‌ی فایل‌های **CSV** و دیتابیس‌های **SQLite** (`.db`، `.sqlite`، `.sqlite3`) داخل یک پوشه را می‌خواند و امکان جستجو در آن‌ها را از داخل تلگرام فراهم می‌کند.

فقط کافی است فایل‌ها را در پوشه‌ی `data/` بگذارید. ربات خودش آن‌ها را پیدا و ثبت می‌کند.

## امکانات
- **ثبت خودکار:** ربات هر ۶۰ ثانیه پوشه را بررسی می‌کند.
  - فایل جدید ثبت می‌شود.
  - فایل تغییرکرده دوباره ثبت می‌شود.
  - فایل حذف‌شده از نتایج حذف می‌شود.
- **زیرپوشه‌ها** هم خوانده می‌شوند.
- **دیتابیس SQLite:** همه‌ی جدول‌های هر فایل `.db` قابل جستجو هستند.
- **فایل‌های چند گیگابایتی:** فایل خط‌به‌خط خوانده می‌شود و مصرف رم حدود ۲۵۰ مگابایت ثابت می‌ماند.
- **فایل در حال کپی:** ربات صبر می‌کند تا کپی تمام شود و بعد ثبتش می‌کند.
- **فارسی:** «ي» و «ی»، «ك» و «ک»، و اعداد فارسی و انگلیسی یکسان در نظر گرفته می‌شوند.
- **تشخیص خودکار** encoding (UTF-8 و Windows-1256 اکسل قدیمی) و جداکننده‌ی CSV (`,` `;` تب `|`).
- **جستجو:** چندکلمه‌ای، با بخشی از ابتدای کلمه، و دقیق با "گیومه". نتایج صفحه‌بندی دارند.
- **پروکسی و آدرس API قابل تغییر** برای جاهایی که تلگرام فیلتر است.
- **دسترسی:** می‌توانید جستجو را به کاربران مشخص محدود کنید.
- **فقط توکن ربات** لازم است. به `API_ID` و `API_HASH` نیازی نیست.

## پیش‌نیازها
- **Python 3.10 یا جدیدتر** (پیشنهاد: 3.13 از [python.org](https://www.python.org/downloads/))
- **فضای دیسک:** حدود ۲ برابر حجم کل فایل‌ها، برای دیتابیس جستجو (`index.db`)
- **دسترسی به تلگرام:** اینترنت آزاد، VPN، یا [آدرس جایگزین API](#عوض-کردن-آدرس-api-تلگرام)

## ساخت ربات در تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید و `/newbot` را بفرستید.
2. یک اسم و یک نام کاربری که به `bot` ختم شود انتخاب کنید.
3. BotFather یک **توکن** مثل `123456789:AAH...` می‌دهد. این همان `BOT_TOKEN` است.
4. شناسه‌ی عددی خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید. این همان `ADMIN_IDS` است.

> توکن را با هیچ‌کس به اشتراک نگذارید و هرگز در گیت‌هاب کامیت نکنید. فایل `.env` در `.gitignore` هست.

## نصب

### مک
1. پایتون 3.13 را از [python.org](https://www.python.org/downloads/macos/) نصب کنید.
2. در صفحه‌ی همین مخزن **Code → Download ZIP** را بزنید و فایل را از حالت فشرده خارج کنید.
3. Terminal را باز کنید:
   ```bash
   cd ~/Downloads/DB-master
   cp .env.example .env
   open -e .env          # BOT_TOKEN و ADMIN_IDS را بنویسید و ذخیره کنید
   bash deploy/mac.sh
   ```
اسکریپت `deploy/mac.sh` این کارها را انجام می‌دهد:
- کتابخانه‌ها را نصب می‌کند.
- تنظیمات را بررسی می‌کند و اگر لازم باشد پروکسی VPN را خودکار پیدا می‌کند.
- ربات را در پس‌زمینه روشن می‌کند و نمی‌گذارد مک به خواب برود.

اگر نسخه‌ی قدیمی را در `~/Downloads/DB-old` دارید، تنظیمات `.env` را خودش از آنجا منتقل می‌کند.

### ویندوز
1. پایتون 3.13 را از [python.org](https://www.python.org/downloads/windows/) نصب کنید. در صفحه‌ی اول نصب تیک **Add python.exe to PATH** را بزنید.
2. **Code → Download ZIP** را بزنید و فایل را از حالت فشرده خارج کنید.
3. در نوار آدرس پوشه‌ی پروژه بنویسید `cmd` و Enter بزنید. بعد:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   notepad .env
   python -m csvbot.check
   python -m csvbot.bot
   ```
پنجره را باز نگه دارید. با بستن پنجره ربات هم خاموش می‌شود.

### لینوکس و سرور
روی Ubuntu یا Debian ربات به‌صورت **سرویس دائمی** نصب می‌شود. بعد از ری‌استارت سرور یا خطا، خودش دوباره روشن می‌شود.
```bash
git clone https://github.com/plaipa/DB.git
cd DB
bash deploy/setup.sh      # بار اول فایل .env را می‌سازد
nano .env                 # BOT_TOKEN و ADMIN_IDS را پر کنید
.venv/bin/python -m csvbot.check
bash deploy/setup.sh      # ربات را به‌صورت سرویس روشن می‌کند
```
راهنمای قدم‌به‌قدم ساخت سرور رایگان Oracle Cloud: [docs/oracle-cloud.md](docs/oracle-cloud.md)

> مخزن خصوصی است. `git clone` نام کاربری و رمز گیت‌هاب را می‌پرسد. به‌جای رمز، یک
> [توکن گیت‌هاب](https://github.com/settings/personal-access-tokens/new) با دسترسی فقط‌خواندنی بسازید و وارد کنید.

راهنمای کامل‌تر اجرا روی کامپیوتر شخصی: [docs/local.md](docs/local.md)

## تنظیمات فایل `.env`
فایل `.env.example` را به `.env` کپی کنید و مقادیر را پر کنید:

| تنظیم | ضروری | توضیح | پیش‌فرض |
|---|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از @BotFather | — |
| `ADMIN_IDS` | پیشنهادی | شناسه‌ی عددی ادمین‌ها، با کاما جدا. ادمین پیام ثبت فایل‌ها را می‌گیرد، می‌تواند `/reload` بزند و فایل بفرستد | — |
| `ALLOWED_USER_IDS` | | فقط این کاربران اجازه‌ی جستجو دارند. خالی یعنی همه | همه |
| `DATA_DIR` | | پوشه‌ی فایل‌ها: مسیر نسبت به پوشه‌ی پروژه، یا مسیر کامل مثل `/Volumes/Disk/files` یا `D:\files` | `data` |
| `DB_PATH` | | فایل دیتابیس جستجو که خودکار ساخته می‌شود | `index.db` |
| `SCAN_INTERVAL` | | فاصله‌ی بررسی پوشه، به ثانیه | `60` |
| `PAGE_SIZE` | | تعداد نتیجه در هر صفحه | `5` |
| `PROXY` | | پروکسی برای رسیدن به تلگرام، مثلاً `socks5://127.0.0.1:10808` | — |
| `TELEGRAM_API_URL` | | آدرس سرور API تلگرام ([توضیح](#عوض-کردن-آدرس-api-تلگرام)) | `https://api.telegram.org` |

بعد از هر تغییر در `.env` ربات را دوباره روشن کنید ([روش](#روشن-و-خاموش-کردن-بهروزرسانی)).

برای بررسی همه‌ی تنظیمات این دستور را بزنید. خروجی آن هیچ رمزی را نشان نمی‌دهد:
```bash
python -m csvbot.check
```

## گذاشتن فایل‌ها
- فایل‌ها را در پوشه‌ی `data/` کپی کنید. ساختن زیرپوشه هم مجاز است.
- **پسوندهای قابل‌قبول:** `.csv`، `.tsv`، `.db`، `.sqlite`، `.sqlite3`
- **ردیف اول CSV** باید اسم ستون‌ها باشد.
- **زمان ثبت:** حداکثر یک دقیقه بعد از تمام شدن کپی، ربات فایل را ثبت می‌کند و به ادمین پیام می‌دهد. برای ثبت فوری `/reload` را بفرستید.
- **ارسال از تلگرام:** ادمین می‌تواند فایل‌های **زیر ۲۰ مگابایت** را مستقیم به ربات بفرستد. فایل در `data/uploads/` ذخیره و ثبت می‌شود. فایل‌های بزرگ‌تر را مستقیم در پوشه کپی کنید.
- **تغییر و حذف:** اگر فایلی را عوض کنید، دوباره ثبت می‌شود. اگر پاکش کنید، از نتایج حذف می‌شود.
- **زمان ثبت فایل‌های بزرگ:** حدود ۵ دقیقه برای هر گیگابایت CSV. در این مدت جستجو در بقیه‌ی فایل‌ها کار می‌کند.
- **فایل `.db`** باید دیتابیس SQLite باشد. فرمت‌های دیگر (مثل دیتابیس MySQL یا Access) نادیده گرفته می‌شوند.

پوشه‌ی `data/` یک فایل نمونه به اسم `people.csv` برای تست دارد. بعد از تست می‌توانید پاکش کنید.

## استفاده از ربات

### دستورها
| دستور | کار | چه کسی |
|---|---|---|
| `/start` | راهنما | همه |
| هر متنی | جستجو | همه، یا فقط `ALLOWED_USER_IDS` |
| `/search متن` | جستجو | همه |
| `/files` | فهرست فایل‌های ثبت‌شده و تعداد ردیف‌ها | همه |
| `/reload` | بررسی فوری پوشه | ادمین |
| ارسال فایل | افزودن فایل زیر ۲۰ مگابایت | ادمین |

### نحوه‌ی جستجو
| نوشتن | نتیجه |
|---|---|
| `علی` | ردیف‌هایی که کلمه‌ای با «علی» شروع می‌شود (علی، علیرضا، ...) |
| `علی تهران` | ردیف‌هایی که **هر دو** کلمه را دارند |
| `"علی رضایی"` | دقیقاً همین عبارت |
| `0912` یا `۰۹۱۲` | فرقی ندارد، اعداد فارسی و انگلیسی یکی هستند |
| `علي` یا `علی` | فرقی ندارد، «ي» عربی و «ی» فارسی یکی هستند |

- **کلمه‌های یک یا دوحرفی** فقط با کلمه‌ی کامل جور می‌شوند. کلمه‌های ۳ حرف به بالا با ابتدای کلمه هم پیدا می‌شوند.
- **شکل نتایج:** هر نتیجه اسم فایل، شماره‌ی ردیف و همه‌ی ستون‌های آن ردیف را نشان می‌دهد. برای دیتابیس‌ها، اسم جدول کنار اسم فایل می‌آید، مثل `people.db › users`.
- **تعداد نتایج:** اگر بیش از ۱۰۰۰ نتیجه باشد، تعداد به‌صورت «1000+» نمایش داده می‌شود. با دکمه‌های «قبلی / بعدی» بین صفحه‌ها جابه‌جا شوید.

## عوض کردن توکن ربات
وقتی توکن لو رفته یا می‌خواهید ربات دیگری را وصل کنید:

1. **گرفتن توکن جدید:**
   - **همان ربات:** در [@BotFather](https://t.me/BotFather) دستور `/revoke` را بفرستید و ربات را انتخاب کنید. توکن قبلی فوراً باطل می‌شود و توکن جدید می‌گیرید. اسم، عکس و کاربرهای ربات همان می‌مانند.
   - **ربات دیگر:** `/newbot` را بزنید و یک ربات تازه بسازید. یا با `/token` توکن یکی از ربات‌های فعلی‌تان را بگیرید.
2. فایل `.env` را باز کنید و خط `BOT_TOKEN=` را با توکن جدید عوض کنید:
   - مک: `open -e .env`
   - ویندوز: `notepad .env`
   - لینوکس: `nano .env`
3. با دستور `python -m csvbot.check` مطمئن شوید که توکن قبول می‌شود.
4. ربات را دوباره روشن کنید ([روش](#روشن-و-خاموش-کردن-بهروزرسانی)).

> نیازی به ثبت دوباره‌ی فایل‌ها نیست. دیتابیس جستجو (`index.db`) به توکن بستگی ندارد.
> با یک توکن فقط **یک** نسخه از ربات می‌تواند روشن باشد. اگر ربات روی دو کامپیوتر روشن باشد، تداخل پیش می‌آید.

## عوض کردن آدرس API تلگرام
ربات به‌طور پیش‌فرض به `https://api.telegram.org` وصل می‌شود. اگر این آدرس در دسترس نیست، می‌توانید آدرس دیگری بدهید که درخواست‌ها را به تلگرام می‌رساند:

```ini
TELEGRAM_API_URL=https://your-mirror.example.com
```

این آدرس می‌تواند یکی از این‌ها باشد:
- **واسط شخصی شما**، مثلاً یک Cloudflare Worker یا یک سرور خارجی که درخواست‌ها را به `api.telegram.org` می‌فرستد
- **سرور [telegram-bot-api](https://github.com/tdlib/telegram-bot-api)** که خودتان راه انداخته‌اید. با این سرور محدودیت ۲۰ مگابایت ارسال فایل به ربات هم برداشته می‌شود.

**شکل آدرس:** فقط ریشه‌ی آدرس را بنویسید، بدون `/bot` و بدون توکن. ربات خودش آدرس کامل را می‌سازد:
- `{TELEGRAM_API_URL}/bot<توکن>/...` برای درخواست‌ها
- `{TELEGRAM_API_URL}/file/bot<توکن>/...` برای دانلود فایل‌ها

بعد از تغییر:
1. با `python -m csvbot.check` اتصال را بررسی کنید.
2. ربات را دوباره روشن کنید.

> ⚠️ تمام پیام‌ها و **توکن ربات** از این آدرس عبور می‌کنند. فقط از سروری استفاده کنید که مال خودتان است یا کاملاً به آن اعتماد دارید. یک واسط ناشناس می‌تواند توکن را بدزدد و کنترل ربات را بگیرد.

`TELEGRAM_API_URL` و `PROXY` را می‌توانید با هم یا جدا استفاده کنید.

## اگر تلگرام فیلتر است (پروکسی و VPN)
سه راه دارید:

1. **VPN در حالت TUN / کل سیستم:** هیچ تنظیمی لازم نیست. `PROXY` را خالی بگذارید.
2. **پروکسی محلی برنامه‌ی VPN:** دستور `python -m csvbot.check` پورت برنامه‌ی VPN را **خودکار پیدا می‌کند** و در `.env` ذخیره می‌کند. اگر خواستید دستی تنظیم کنید:

   | برنامه | مقدار معمول |
   |---|---|
   | v2rayN | `PROXY=socks5://127.0.0.1:10808` |
   | V2RayU | `PROXY=socks5://127.0.0.1:1080` |
   | Nekoray / NekoBox / sing-box | `PROXY=socks5://127.0.0.1:2080` |
   | Hiddify | `PROXY=socks5://127.0.0.1:12334` |
   | Clash / Clash Verge | `PROXY=http://127.0.0.1:7890` |

3. **آدرس جایگزین API:** [بخش بالا](#عوض-کردن-آدرس-api-تلگرام) را ببینید.

## روشن و خاموش کردن، به‌روزرسانی

| کار | مک | ویندوز | لینوکس (سرویس) |
|---|---|---|---|
| روشن کردن | `bash deploy/mac.sh` | `python -m csvbot.bot` | `sudo systemctl start csvbot` |
| خاموش کردن | `pkill -f '[.]venv/bin/python -m csvbot[.]bot'` | `Ctrl+C` در پنجره | `sudo systemctl stop csvbot` |
| روشن کردن دوباره | `bash deploy/mac.sh` | `Ctrl+C` و اجرای دوباره | `sudo systemctl restart csvbot` |
| دیدن لاگ | `tail -f bot.log` | همان پنجره | `journalctl -u csvbot -f` |

**به‌روزرسانی:**
- **مک و ویندوز:** نسخه‌ی جدید را دانلود کنید. فایل `.env`، پوشه‌ی `data` و `index.db` را از نسخه‌ی قبلی به نسخه‌ی جدید کپی کنید.
- **لینوکس:** `git pull && bash deploy/setup.sh`

## عیب‌یابی
اول همیشه این دستور را بزنید. مرحله‌به‌مرحله بررسی می‌کند و برای هر مشکل راه‌حل می‌گوید:
```bash
python -m csvbot.check
```

| مشکل | راه‌حل |
|---|---|
| `BOT_TOKEN is not set` | فایل `.env` پر نشده، یا اسمش `.env.txt` یا `.env.rtf` شده |
| `Telegram rejected BOT_TOKEN` | توکن اشتباه یا باطل است: [عوض کردن توکن](#عوض-کردن-توکن-ربات) |
| `Cannot reach Telegram` / `NetworkError` | VPN خاموش است یا `PROXY` / `TELEGRAM_API_URL` اشتباه است |
| `Conflict: terminated by other getUpdates` | ربات هم‌زمان جای دیگری هم روشن است. یکی را خاموش کنید |
| `SQLite >= 3.43 is required` | پایتون قدیمی است. 3.13 را نصب کنید |
| ربات جواب «فقط ادمین» می‌دهد | شناسه‌ی شما در `ADMIN_IDS` نیست |
| فایل ثبت نمی‌شود | `/reload` را بزنید و لاگ را ببینید. فایل `.db` باید SQLite باشد. پسوند فایل را بررسی کنید |
| نتایج CSV به‌هم‌ریخته‌اند | ردیف اول فایل باید اسم ستون‌ها باشد |
| `'python' is not recognized` (ویندوز) | به‌جای `python` بنویسید `py`، یا پایتون را با تیک Add to PATH دوباره نصب کنید |

## امنیت و استفاده‌ی مسئولانه
- فایل `.env` (توکن) و پوشه‌ی `data/` را هرگز در گیت‌هاب یا جای عمومی قرار ندهید. هر دو در `.gitignore` هستند.
- اگر داده‌ها اطلاعات شخصی دارند، حتماً `ALLOWED_USER_IDS` را پر کنید. در غیر این صورت هر کسی ربات را پیدا کند می‌تواند در آن جستجو کند.
- این ربات را فقط روی داده‌هایی استفاده کنید که مال خودتان است یا اجازه‌ی استفاده از آن‌ها را دارید. جستجو روی اطلاعات شخصیِ لو رفته یا جمع‌آوری‌شده بدون رضایت افراد، به آن‌ها آسیب می‌زند و در بسیاری از کشورها غیرقانونی است.
