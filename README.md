# ربات جستجو در فایل‌های CSV تلگرام

ربات فایل‌های CSV کانال را دانلود می‌کند، محتوایشان را در SQLite (جستجوی تمام‌متن FTS5) ذخیره می‌کند و از داخل تلگرام جستجو می‌کند.
برای فایل‌های چند گیگابایتی ساخته شده: به‌جای Bot API (محدودیت ۲۰ مگابایت) از **Telethon / MTProto** استفاده می‌کند و فایل را خط‌به‌خط می‌خواند، پس مصرف رم (حدود ۲۵۰ مگابایت) به حجم فایل بستگی ندارد.

## امکانات
- ثبت خودکار فایل‌های CSV جدید کانال
- ثبت فایل‌های قدیمی: فوروارد به ربات، یا اسکریپت `csvbot.sync` که کل کانال را یک‌جا می‌خواند
- یکسان‌سازی حروف و اعداد فارسی/عربی (ي/ی، ك/ک، ۱۲۳/123)
- تشخیص خودکار encoding (UTF-8، Windows-1256) و جداکننده (`,` `;` تب `|`)
- جستجوی چندکلمه‌ای، پیشوندی (کلمات ۳ حرف به بالا)، دقیق با "گیومه"، صفحه‌بندی
- اگر پردازش وسط کار قطع شود، داده ناقص در اجرای بعدی پاک می‌شود

## نیازمندی‌ها
- Python 3.10+ با SQLite 3.43 یا جدیدتر
- **فضای دیسک:** حدود ۲ برابر حجم کل CSVها برای دیتابیس + فضای بزرگ‌ترین فایل برای دانلود موقت
  (مثال: ۱۰ فایل ۳ گیگی ≈ ۶۰ گیگ دیتابیس + ۳ گیگ موقت)

## راه‌اندازی
> - تست روی کامپیوتر خودتان (ویندوز/مک/لینوکس، با VPN): [docs/local.md](docs/local.md)
> - نصب دائمی روی **Oracle Cloud Free Tier**: [docs/oracle-cloud.md](docs/oracle-cloud.md)

1. در [my.telegram.org](https://my.telegram.org) → API development tools مقادیر `API_ID` و `API_HASH` را بگیرید.
2. در [@BotFather](https://t.me/BotFather) ربات بسازید و توکن بگیرید.
3. ربات را در کانال **ادمین** کنید.
4. شناسه عددی خود را از [@userinfobot](https://t.me/userinfobot) بگیرید.
5. نصب و اجرا:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # مقادیر را پر کنید
   python -m csvbot.bot
   ```

## ثبت فایل‌های قدیمی کانال
**روش ۱ — فوروارد:** فایل‌ها را از کانال به ربات فوروارد کنید. ربات درصد دانلود و تعداد ردیف‌ها را نشان می‌دهد. فایل‌ها به‌ترتیب و یکی‌یکی پردازش می‌شوند.

**روش ۲ — همگام‌سازی کامل (پیشنهادی برای تعداد زیاد):**
```bash
python -m csvbot.sync
```
بار اول شماره تلفن و کد ورود حساب خودتان را می‌پرسد (ربات‌ها به تاریخچه کانال دسترسی ندارند). فایل‌های تکراری را رد می‌کند و می‌توانید هر بار دوباره اجرایش کنید.

**روش ۳ — فایل‌های روی کامپیوتر:**
```bash
python import_csv.py file1.csv file2.csv
```
