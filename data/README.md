# پوشه‌ی داده

فایل‌های `.csv`، `.tsv` و دیتابیس‌های SQLite (`.db`، `.sqlite`، `.sqlite3`) را اینجا بگذارید؛ ربات حداکثر یک دقیقه بعد آن‌ها را ثبت می‌کند.

`sample.csv` فقط یک نمونه‌ی ساختگی است تا بعد از نصب بتوانید سریع امتحان کنید (مثلاً «زعفران» یا «مشهد» را جستجو کنید). هر وقت خواستید پاکش کنید؛ ربات آن را هم از ایندکس برمی‌دارد.

محتوای این پوشه (جز همین دو فایل) در گیت ثبت نمی‌شود.
