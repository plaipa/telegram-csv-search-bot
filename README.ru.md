# Telegram-бот для поиска по CSV и SQLite

> Бесплатный бот с открытым исходным кодом, который **ищет внутри CSV, TSV и SQLite (`.db`) файлов прямо в Telegram**. Положите файлы в папку и ищите по ним, даже если они весят несколько гигабайт. Полнотекстовый поиск для **русского, английского, персидского, хинди и китайского**. Работает на macOS, Windows, Linux и в Docker.

Ключевые слова: telegram бот, поиск по csv, поиск в csv файле, поиск по sqlite, большие csv файлы, полнотекстовый поиск, python-telegram-bot, self-hosted.

## Возможности
- **Слежение за папкой:** кладите `.csv`, `.tsv`, `.db`, `.sqlite`, `.sqlite3` в `data/`. Новые файлы индексируются автоматически, изменённые индексируются заново, удалённые пропадают из выдачи.
- **Огромные файлы:** CSV читается потоком, поэтому память остаётся около 250 МБ даже для файла 3 ГБ и больше. CSV на 6 млн строк индексируется примерно за 2,5 минуты, большинство запросов выполняется быстрее 200 мс (SQLite FTS5).
- **Базы SQLite:** поиск по всем таблицам каждого `.db` файла (файл открывается только для чтения).
- **Много языков:** цифры (`0912`, `۰۹۱۲`, `०९१२`) считаются одинаковыми, арабские диакритики и «нукта» в хинди убираются, а китайский текст ищется по любой части фразы (`北京` найдётся в «我在北京工作»). Кодировка (UTF-8, UTF-16, GBK, Big5, Windows-1251/1256) и разделитель (`, ; | tab`) определяются автоматически.
- **Синтаксис поиска:** несколько слов (должны встретиться все), начало слова (от 3 символов), `"точная фраза"`, кнопки страниц.
- **Контроль доступа:** по умолчанию бот закрыт; администратор добавляет и удаляет пользователей прямо в чате (`/adduser`, `/deluser`).
- **Безопасность:** лимиты поисков и результатов на пользователя, журнал всех запросов (`/audit`).
- **Инструменты администратора:** загрузка небольших файлов в чат, `/reload`, удаление строки из индекса или из исходного файла.
- **Нужен только токен бота** (без `API_ID` и `API_HASH`). Есть прокси и свой сервер Bot API для регионов, где Telegram заблокирован.

## Быстрый старт

### 1. Создайте бота
1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте **токен**.
2. Узнайте свой числовой id у [@userinfobot](https://t.me/userinfobot); это `ADMIN_IDS`.

### 2. Установка

**Docker** (любая ОС)
```bash
git clone https://github.com/plaipa/telegram-csv-search-bot.git
cd telegram-csv-search-bot
cp .env.example .env        # заполните BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
```

**Python 3.10+** (macOS / Linux)
```bash
cp .env.example .env        # заполните BOT_TOKEN и ADMIN_IDS
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m csvbot.check   # проверяет настройки и доступ к Telegram
.venv/bin/python -m csvbot.bot
```
В Windows используйте `py -m venv .venv`, `.venv\Scripts\pip` и `.venv\Scripts\python`. На Linux-сервере `bash deploy/setup.sh` создаёт службу systemd; на macOS: `bash deploy/mac.sh`. Нужен SQLite 3.43 или новее (проверка: `python -m csvbot.check`; в Docker он уже есть).

### 3. Добавьте файлы и ищите
Скопируйте CSV / SQLite файлы в `data/` (там лежит вымышленный `sample.csv`). В течение минуты администратор получит сообщение «файл проиндексирован». После этого отправьте боту любое слово.

## Настройки (`.env`)
| Параметр | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather (обязательно) | — |
| `ADMIN_IDS` | Числовые id администраторов через запятую | — |
| `ALLOWED_USER_IDS` | Дополнительные пользователи (кроме администраторов и добавленных через `/adduser`) | — |
| `DATA_DIR` | Папка с файлами (относительный или полный путь) | `data` |
| `DB_PATH` | Файл поискового индекса (создаётся сам) | `index.db` |
| `SCAN_INTERVAL` | Интервал проверки папки, секунд | `60` |
| `PAGE_SIZE` | Результатов на страницу | `5` |
| `SEARCH_LIMIT_HOUR` / `SEARCH_LIMIT_DAY` | Поисков на обычного пользователя в час / сутки (`0` = без лимита) | `60` / `300` |
| `MAX_RESULTS` | Сколько результатов обычный пользователь может листать в одном поиске (`0` = без лимита) | `50` |
| `AUDIT_DAYS` | Сколько дней хранить журнал поисков (`0` = всегда) | `180` |
| `PROXY` | например `socks5://127.0.0.1:10808` | — |
| `TELEGRAM_API_URL` | Свой сервер Bot API | `https://api.telegram.org` |

После любых изменений запускайте `python -m csvbot.check`; он не выводит секреты.

## Команды бота
| Команда | Действие | Кому |
|---|---|---|
| любой текст, `/search текст` | Поиск | администраторам и разрешённым пользователям |
| `/start` | Справка; без доступа пользователь видит, как связаться с администратором | всем |
| `/files` | Список проиндексированных файлов | администратор |
| `/reload` | Проверить папку сейчас | администратор |
| `/users` | Список разрешённых пользователей с кнопкой ❌ для удаления | администратор |
| `/adduser ID`, `/deluser ID` | Добавить или удалить пользователя по числовому id | администратор |
| `/audit [ID]` | Последние поиски (кто, когда, что) | администратор |
| кнопка 🗑 под результатами | Удалить строку из индекса или ещё и из исходного файла (необратимо) | администратор |
| отправка файла | Добавить CSV/DB меньше 20 МБ | администратор |

> **Самый простой способ добавить пользователя:** человек отправляет боту `/start` и нажимает **📩 Запросить доступ**. Каждый администратор получает сообщение с кнопками **✅ Одобрить / ❌ Отклонить**, а пользователь узнаёт результат. Копировать id не нужно.

## Сменить токен или сервер Telegram API
- **Токен:** отправьте BotFather `/revoke` (тот же бот) или `/newbot`, впишите новый токен в `BOT_TOKEN` в `.env`, запустите `python -m csvbot.check` и перезапустите бота. На один токен — один запущенный экземпляр.
- **Сервер API:** задайте `TELEGRAM_API_URL=https://your-mirror.example.com` (обратный прокси, Cloudflare Worker или собственный [telegram-bot-api](https://github.com/tdlib/telegram-bot-api); последний ещё и снимает лимит 20 МБ на загрузку). Токен бота проходит через этот сервер, поэтому используйте только свой или полностью доверенный.
- **Прокси / VPN:** `PROXY=socks5://127.0.0.1:10808`. `python -m csvbot.check` умеет находить локальный прокси сам.

## Ответственное использование, лицензия и отказ от гарантий
Бот — универсальный инструмент поиска по файлам. В комплекте нет никаких данных, он ничего никуда не отправляет и ничего не собирает; каждая установка независима и читает только файлы, которые **вы** положили в `data/`. Вы отвечаете за свои данные и за соблюдение местных законов (включая законы о защите персональных данных) и правил Telegram. Не используйте бот для поиска по персональным данным, собранным или утёкшим без согласия людей. Не добавляйте `.env` и `data/` в git.
