# टेलीग्राम CSV और SQLite सर्च बॉट

> CSV, TSV और SQLite (`.db`) फ़ाइलों के अंदर खोजने वाला **मुफ़्त, ओपन-सोर्स टेलीग्राम बॉट**। अपनी फ़ाइलें एक फ़ोल्डर में रखें और टेलीग्राम से खोजें, कई GB की फ़ाइलें भी। **हिन्दी, फ़ारसी, अरबी और अंग्रेज़ी** टेक्स्ट के लिए फ़ुल-टेक्स्ट सर्च। macOS, Windows, Linux और Docker पर चलता है।

कीवर्ड: टेलीग्राम बॉट, CSV सर्च, CSV फ़ाइल में खोजें, SQLite सर्च, बड़ी CSV फ़ाइल, डेटाबेस सर्च बॉट, python-telegram-bot, हिन्दी सर्च।

## विशेषताएँ
- **फ़ोल्डर की निगरानी:** `.csv`, `.tsv`, `.db`, `.sqlite`, `.sqlite3` फ़ाइलें `data/` में रखें। नई फ़ाइल अपने-आप इंडेक्स होती है, बदली हुई फ़ाइल दोबारा इंडेक्स होती है और हटाई गई फ़ाइल नतीजों से गायब हो जाती है।
- **बहुत बड़ी फ़ाइलें:** CSV को लाइन-दर-लाइन पढ़ा जाता है, इसलिए 3 GB से बड़ी फ़ाइल पर भी मेमोरी लगभग 250 MB रहती है। 60 लाख पंक्तियों की CSV करीब 2.5 मिनट में इंडेक्स होती है और ज़्यादातर खोजें 200 ms से कम में पूरी होती हैं (SQLite FTS5)।
- **SQLite डेटाबेस:** हर `.db` फ़ाइल की सभी तालिकाओं (tables) में खोज सकते हैं; फ़ाइल सिर्फ़ पढ़ने के मोड में खुलती है।
- **बहुभाषी टेक्स्ट:** देवनागरी अंक (`०९१२`), फ़ारसी/अरबी अंक और `0912` एक जैसे माने जाते हैं। नुक़्ता (फ़ = फ) और अरबी हरकतें हटा दी जाती हैं। एन्कोडिंग (UTF-8, UTF-16, GBK, Big5, Windows-1251/1256) और विभाजक (`, ; | tab`) अपने-आप पहचाने जाते हैं।
- **खोज का तरीका:** कई शब्द (सभी का मिलना ज़रूरी), शब्द की शुरुआत (3+ अक्षर), `"पूरा वाक्यांश"` और पेज बटन।
- **एक्सेस कंट्रोल:** बॉट शुरू से बंद रहता है; एडमिन चैट से ही यूज़र जोड़/हटा सकता है (`/adduser`, `/deluser`)।
- **सुरक्षा:** हर यूज़र के लिए खोज और नतीजों की सीमा, और हर खोज का ऑडिट लॉग (`/audit`)।
- **एडमिन टूल:** चैट में छोटी फ़ाइल भेजना, `/reload`, किसी पंक्ति को इंडेक्स से या मूल फ़ाइल से भी हटाना।
- **सिर्फ़ बॉट टोकन चाहिए** (`API_ID` / `API_HASH` नहीं)। जहाँ टेलीग्राम बंद है वहाँ प्रॉक्सी और कस्टम Bot API सर्वर का विकल्प है।

## जल्दी शुरू करें

### 1. बॉट बनाएँ
1. टेलीग्राम में [@BotFather](https://t.me/BotFather) को `/newbot` भेजें और **टोकन** कॉपी करें।
2. अपनी संख्यात्मक आईडी [@userinfobot](https://t.me/userinfobot) से लें; यही `ADMIN_IDS` है।

### 2. इंस्टॉल करें

**Docker** (किसी भी OS पर)
```bash
git clone https://github.com/plaipa/telegram-csv-search-bot.git telegram-csv-search-bot
cd telegram-csv-search-bot
cp .env.example .env        # BOT_TOKEN और ADMIN_IDS भरें
docker compose up -d --build
```

**Python 3.10+** (macOS / Linux)
```bash
cp .env.example .env        # BOT_TOKEN और ADMIN_IDS भरें
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m csvbot.check   # सेटिंग और टेलीग्राम कनेक्शन जाँचता है
.venv/bin/python -m csvbot.bot
```
Windows पर `py -m venv .venv`, `.venv\Scripts\pip` और `.venv\Scripts\python` इस्तेमाल करें। Linux सर्वर पर `bash deploy/setup.sh` systemd सर्विस बनाता है; macOS पर `bash deploy/mac.sh`। SQLite 3.43 या नया चाहिए (`python -m csvbot.check` से जाँचें; Docker में पहले से है)।

### 3. फ़ाइलें रखें और खोजें
CSV / SQLite फ़ाइलें `data/` में कॉपी करें (एक काल्पनिक `sample.csv` साथ में है)। एक मिनट के भीतर एडमिन को "फ़ाइल इंडेक्स हो गई" का संदेश मिलता है। फिर बॉट को कोई भी शब्द भेजें।

## सेटिंग (`.env`)
| सेटिंग | विवरण | डिफ़ॉल्ट |
|---|---|---|
| `BOT_TOKEN` | @BotFather से मिला टोकन (ज़रूरी) | — |
| `ADMIN_IDS` | एडमिन की संख्यात्मक आईडी, कॉमा से अलग | — |
| `ALLOWED_USER_IDS` | एडमिन और `/adduser` के अलावा अनुमत यूज़र | — |
| `DATA_DIR` | फ़ाइलों वाला फ़ोल्डर (सापेक्ष या पूरा पथ) | `data` |
| `DB_PATH` | सर्च इंडेक्स फ़ाइल (अपने-आप बनती है) | `index.db` |
| `SCAN_INTERVAL` | फ़ोल्डर जाँचने का अंतराल (सेकंड) | `60` |
| `PAGE_SIZE` | प्रति पेज नतीजे | `5` |
| `SEARCH_LIMIT_HOUR` / `SEARCH_LIMIT_DAY` | सामान्य यूज़र की खोजें प्रति घंटा / दिन (`0` = असीमित) | `60` / `300` |
| `MAX_RESULTS` | एक खोज में सामान्य यूज़र कितने नतीजे देख सकता है (`0` = असीमित) | `50` |
| `AUDIT_DAYS` | खोज लॉग कितने दिन रखें (`0` = हमेशा) | `180` |
| `PROXY` | जैसे `socks5://127.0.0.1:10808` | — |
| `TELEGRAM_API_URL` | कस्टम Bot API सर्वर | `https://api.telegram.org` |

हर बदलाव के बाद `python -m csvbot.check` चलाएँ; यह कोई गोपनीय जानकारी नहीं दिखाता।

## बॉट के कमांड
| कमांड | काम | किसके लिए |
|---|---|---|
| कोई भी टेक्स्ट, `/search टेक्स्ट` | खोजें | एडमिन और अनुमत यूज़र |
| `/start` | मदद; पहुँच न होने पर एडमिन से संपर्क करने का संदेश | सभी |
| `/files` | इंडेक्स हुई फ़ाइलों की सूची | एडमिन |
| `/reload` | फ़ोल्डर अभी जाँचें | एडमिन |
| `/adduser ID`, `/deluser ID`, `/users` | अनुमत यूज़र प्रबंधित करें | एडमिन |
| `/audit [ID]` | हाल की खोजें (किसने, कब, क्या) | एडमिन |
| नतीजों के नीचे 🗑 बटन | पंक्ति को इंडेक्स से, या मूल फ़ाइल से भी हटाएँ (वापस नहीं होगा) | एडमिन |
| फ़ाइल भेजना | 20 MB से छोटी CSV/DB जोड़ें | एडमिन |

## टोकन या Telegram API सर्वर बदलना
- **टोकन:** BotFather में `/revoke` (वही बॉट) या `/newbot` भेजें, नया टोकन `.env` के `BOT_TOKEN` में डालें, `python -m csvbot.check` चलाएँ और बॉट दोबारा शुरू करें। एक टोकन पर सिर्फ़ एक इंस्टेंस चलाएँ।
- **API सर्वर:** `TELEGRAM_API_URL=https://your-mirror.example.com` सेट करें (रिवर्स प्रॉक्सी, Cloudflare Worker या अपना [telegram-bot-api](https://github.com/tdlib/telegram-bot-api) सर्वर; आख़िरी विकल्प से 20 MB अपलोड सीमा भी हट जाती है)। बॉट टोकन उसी सर्वर से गुज़रता है, इसलिए केवल अपना या भरोसेमंद सर्वर इस्तेमाल करें।
- **प्रॉक्सी / VPN:** `PROXY=socks5://127.0.0.1:10808`। `python -m csvbot.check` लोकल प्रॉक्सी अपने-आप खोज सकता है।

## ज़िम्मेदार उपयोग, लाइसेंस और अस्वीकरण
यह बॉट एक सामान्य फ़ाइल-सर्च टूल है। इसके साथ कोई डेटा नहीं आता, यह कहीं डेटा नहीं भेजता और कुछ इकट्ठा नहीं करता; हर इंस्टॉलेशन स्वतंत्र है और केवल वही फ़ाइलें पढ़ता है जो **आप** `data/` में रखते हैं। अपने डेटा और स्थानीय क़ानूनों (निजी डेटा संरक्षण क़ानून सहित) तथा टेलीग्राम की शर्तों के पालन की ज़िम्मेदारी आपकी है। लोगों की सहमति के बिना इकट्ठा किए या लीक हुए निजी डेटा को खोजने के लिए इसका उपयोग न करें। `.env` और `data/` को git में न डालें।
